# Heading fonts

These Latin WOFF2 subsets are served locally and include Spanish characters.

- **Caveat**, weight 600: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/caveat). License: `caveat-LICENSE.txt`.
- **Barlow Condensed**, weight 700: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/barlowcondensed). License: `barlow-condensed-LICENSE.txt`.
- **Lobster Two**, weight 700 italic: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/lobstertwo). License: `lobster-two-LICENSE.txt`.

The files were obtained from Google Fonts' CSS2 distribution. All families are distributed under the SIL Open Font License 1.1. No font service is contacted by the application at runtime.
